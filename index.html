Bug Slayer — AI-Powered Repository Assistant

Problem Statement: Setting up unfamiliar repositories can be difficult. README instructions may be outdated, dependencies may fail, and developers often have to debug installation problems manually.

Solution Architecture: Bug Slayer is an AI-powered repository assistant with two modes:
  • Healer: Parses setup instructions, executes commands in a controlled environment, analyses failures using Gemma, and tests suggested fixes.
  • Architect: Inspects a repository's structure and generates a README with verified setup instructions.

Individual Contribution: Worked on AI integration and backend development, contributing to the connection between the AI model and the application's repository-analysis and problem-solving workflows.

Perplexity Explorer — Language Model Playground

Problem Statement: Language-model concepts such as token probabilities and perplexity can be difficult to understand without seeing the underlying calculations.

Solution Architecture: An interactive browser-based application that accepts text, processes it through DistilGPT-2, displays token probabilities, calculates perplexity using negative log-likelihood, and presents likely next-token predictions. It also includes a probability exploration sandbox.

Individual Contribution: Built the interactive interface and implemented the browser-side model inference and probability visualisation workflow.

LLM Tokenizer & Vector Lab

Problem Statement: Understanding how text moves through an LLM pipeline—from tokenization to numerical representations—is challenging when concepts are presented only theoretically.

Solution Architecture: An interactive educational tool that demonstrates text processing, tokenization, token IDs, embedding concepts, positional encoding, and vector-space visualisation. Users can experiment with vocabulary and inspect word positions in a 3D environment.

Individual Contribution: Developed the interactive pipeline experience, vocabulary tools, and 3D vector-space visualisation.

Technical note: The current vector visualisation uses simulated deterministic vectors and semantic clusters rather than embeddings extracted from a trained model.
