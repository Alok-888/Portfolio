01 / 04 AI Tooling & Backend

Bug Slayer

An AI-powered repository assistant with Healer and Architect modes for repository analysis, controlled execution, AI integration, and verified README generation.

Problem

Setting up unfamiliar repositories can be difficult when README instructions are outdated, dependencies fail, and developers have to debug installation issues manually.

Solution
  • Healer Mode: Parses setup instructions, executes commands inside a controlled environment, analyses failures using Gemma, and tests suggested fixes.
  • Architect Mode: Inspects a repository's structure and generates a README with verified setup instructions.
Contribution

Worked on AI integration and backend development, connecting the AI model to the application's repository-analysis and problem-solving workflows.

FIG 02 / LOG-LIKELIHOOD DISTILGPT-2 IN BROWSER
02 / 04 Client-Side ML Playground

Perplexity Explorer

An interactive browser-based language model playground featuring token probabilities, perplexity calculations, and next-token predictions.

Problem

Language-model concepts such as token probabilities and perplexity can be difficult to understand without inspecting the underlying calculations directly.

Solution

Processes user text through DistilGPT-2 directly in the browser, visualising per-token probabilities, computing perplexity via negative log-likelihood, presenting likely next-token predictions, and offering a probability exploration sandbox.

Contribution

Built the interactive interface and implemented the browser-side model inference and probability visualisation workflow.

FIG 03 / VECTOR PROJECTION THREE.JS LAB
03 / 04 3D Visualisation & EdTech

LLM Tokenizer & Vector Lab

An interactive educational application demonstrating tokenization, token IDs, embeddings, positional encoding, and 3D vector-space visualisation.

Problem

Understanding how text moves through an LLM pipeline—from tokenization to numerical representations—is challenging when concepts are presented only theoretically.

Solution

An interactive educational pipeline demonstrating text processing, tokenization, token IDs, embedding concepts, positional encoding, and vector-space visualisation where users can experiment with vocabulary and inspect word positions in a 3D environment.

Contribution

Developed the interactive pipeline experience, vocabulary tools, and 3D vector-space visualisation.

Technical clarification: The current vector visualisation uses simulated deterministic vectors and semantic clusters rather than embeddings extracted from a trained model.
